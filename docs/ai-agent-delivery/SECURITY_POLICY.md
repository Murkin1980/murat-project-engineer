# Политика доступа

PRIVATE/UNKNOWN закрыты по умолчанию. SELECTIVE — только явно утверждённые публичные пути. robots.txt и Content Signals выражают предпочтения; авторизацию обеспечивают реальные средства доступа. Не обращаться к частным материалам и не включать их в fixtures, логи или сравнения. Инструмент расчёта возвращает только разрешённые поля публичного прайса. Проверять валидность единиц, диапазонов, версии и отсутствие внутренних полей на синтетических объектах. При утечке остановить тест, закрыть тестовую поверхность и передать владельцу минимальные обезличенные сведения.
