# Правила исследований

До сбора данных заморозить корпус вопросов, даты, контрольные URL и критерии ошибок. Минимальный план — три независимых повтора каждого вопроса на поверхность, в разные сессии; пилот оценивает разброс, а не статистическую мощность. Отдельно фиксировать ответы без ссылок, недоступный режим, API и consumer UI. Связывать источник с конкретным утверждением. Единичный ответ и кейс поставщика не устанавливают причинность. При смешении вариантов в кеше остановить серию и переснять baseline. Смена модели или цены начинает новую серию.
