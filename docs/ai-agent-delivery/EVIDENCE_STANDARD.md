# Доказательства и стоимость

Для каждого наблюдения сохранять SHA, hash корпуса, версию прайса, run_id, UTC, регион, язык, поверхность, запрос, вариант, raw evidence без PII, доступность, ошибку, ссылку и ручную оценку. Приводить числитель, знаменатель, разброс повторов, пропуски и возможные смешивающие факторы. Для бизнес-ценности измерять минуты до сметы, исправления менеджером, часы проверки и KZT на подтверждённую полезную смету. Учёт реферального перехода отдельно от подтверждения обращения. При отсутствии данных записать UNKNOWN.
