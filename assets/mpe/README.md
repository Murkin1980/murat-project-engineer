# MPE Assets

Canonical visual assets for **Murat Project Engineer (MPE)**.

## Current approved direction

- Mark: three ascending pseudo-3D blocks.
- One letter per step: **M → P → E**.
- Do not merge or overlap the letters.
- Preferred browser/favicon treatment: **light background**.
- Keep the small-size mark simple and high-contrast.
- Horizontal product logo: MPE mark + `MPE` + `MURAT PROJECT ENGINEER`.

## Files

- `mpe-mark-light.svg` — preferred favicon / browser-tab / light UI mark.
- `mpe-mark-dark.svg` — dark-surface variant.
- `mpe-logo-horizontal-light.svg` — horizontal website/product header lockup.

## Usage

Use the mark alone for favicon, app icon, compact navigation, and square avatars.
Use the horizontal lockup where the product name needs to be explicit.

This branch is the working home for future website assets. New assets should be organized under `assets/<product>/...` rather than mixed into application code.
