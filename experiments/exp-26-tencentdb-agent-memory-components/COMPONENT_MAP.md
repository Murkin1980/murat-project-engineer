## Exact components worth reusing

1. **Transient symbolic context packet:** a compact Mermaid/structured view of exact approved facts, retaining stable memory IDs and canonical source references. It is a context projection, never a replacement record or autonomous write target.
2. **Read-only L2 scenario card with progressive disclosure:** project scope + complete decision/constraint + item IDs + source refs in the bootstrap view; retrieve L1 metadata only when needed. Build it as a derived view over the existing EXP-15 records, not a second canonical store.
3. **Budget and pointer discipline:** keep the top-level context bounded and make every omitted detail reachable through a stable, auditable pointer. Do not adopt the upstream service stack or its extraction/retrieval runtime.

These are **candidate reusable patterns**, not a verified Relief Atom or VRU: the comparison used retrospective frozen fixtures and did not deliver/test relief in a live or production-like workflow.
