preflight.mjs вызывает закреплённую функцию локально, сверяет базовые суммы с независимым CSV. Ядро пригодно для арифметики; проверку единиц и границ выполняет вызывающая сторона. Локальный вызов не подтверждает инструментальный вызов из Arena. Исходные файлы сметы, этот ключ, производственные данные и логи остаются вне модельного запроса. До допуска отправок нет. Для последующего допуска разрешён только проверенный розничный контракт и один согласованный запрос.
