# Цитирование и ценность

Статус PLANNED, EXP-50. Гипотезы H10–H11, H13. Метод: Парные брендовые и небрендовые запросы RU/KZ. Наблюдать сопоставимые контрольные страницы до/после, отдельно анализировать пять систем, конкурентов, авторство Murat House и коммерческий funnel.

Baseline и контроль: исходный canonical HTML, прежний пользовательский путь, тот же корпус, регион, язык и версия. Сохранять неизменную контрольную группу. Evidence: обезличенный журнал и исходные ссылки. Метрики: Цитаты с корректной ссылкой / все ответы, правильный автор / цитаты, квалифицированные обращения / атрибутируемые сессии, стоимость результата.

Результат: NOT RUN. Ограничения: дрейф модели, доступ аккаунта, неполная атрибуция. Cost: до старта согласовать потолок времени и платных вызовов, в отчёте часы и KZT. Arena выполняет, Codex независимо перепроверяет. Применимость только к проверенным поверхностям и бренду. Rollback: снять вариант, вернуть контрольный снимок, отозвать тестовые инструменты.
