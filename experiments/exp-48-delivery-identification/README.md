# Доставка и идентификация

Статус PLANNED, EXP-48. Гипотезы H01–H05. Метод: Один утверждённый HTML-снимок и одинаковые факты в HTML, Markdown и JSON-LD; парный каталог с/без llms.txt и контроль без edge. Менять один фактор за проход. Классифицировать поисковый, пользовательский и неподтверждённый запрос.

Baseline и контроль: исходный canonical HTML, прежний пользовательский путь, тот же корпус, регион, язык и версия. Сохранять неизменную контрольную группу. Evidence: обезличенный журнал и исходные ссылки. Метрики: Доля правильно извлечённых полей, ошибочных идентификаций, байты, время, расхождения с HTML.

Результат: NOT RUN. Ограничения: дрейф модели, доступ аккаунта, неполная атрибуция. Cost: до старта согласовать потолок времени и платных вызовов, в отчёте часы и KZT. Arena выполняет, Codex независимо перепроверяет. Применимость только к проверенным поверхностям и бренду. Rollback: снять вариант, вернуть контрольный снимок, отозвать тестовые инструменты.
